# Инструкция пользователя приложения «Шлагбаум»

## 1. Установка приложения

1. Получите установочный файл приложения Android (APK) у администратора.
2. Скачайте файл на телефон.
3. Откройте скачанный APK.
4. Если Android попросит разрешение на установку из неизвестного источника, разрешите установку для используемого приложения (например, браузера или файлового менеджера).
5. Завершите установку.

На рабочем столе появится приложение **«Шлагбаум»**.

## 2. Вход в приложение

1. Запустите приложение «Шлагбаум».
2. Введите номер телефона, указанный при регистрации.
3. Введите свой пароль.
4. Нажмите кнопку входа.

Если учётная запись ещё не активирована или заблокирована, войти или открыть шлагбаум не получится. Обратитесь к администратору.

## 3. Открытие шлагбаума

1. Откройте приложение.
2. Убедитесь, что телефон подключён к интернету.
3. На главном экране нажмите кнопку открытия шлагбаума.
4. Дождитесь ответа сервера.

Приложение покажет результат выполнения команды.

**Важно:** не нажимайте кнопку многократно подряд. Дождитесь результата предыдущего запроса.

## 4. Быстрое открытие

В приложении предусмотрен дополнительный ярлык Android — **«Быстро открыть»**.

Чтобы воспользоваться им:

1. Найдите иконку приложения «Шлагбаум» на рабочем столе.
2. Нажмите на неё и удерживайте.
3. В появившемся меню выберите «Быстро открыть».
4. Дождитесь результата выполнения команды.

При использовании быстрого ярлыка основной экран приложения открывать не требуется.
Можно вытянуть «Быстро открыть» на свободное метро рабочего стола и появится ярлык для бытрого открытия.
Если ярлык не появился, проверьте, что установлена версия приложения с поддержкой быстрого открытия.

## 5. История открытий

В приложении доступна история открытий шлагбаума.

В ней можно посмотреть зарегистрированные системой события, если они были получены от сервера.

## 6. Управление родственниками

Собственник может добавлять родственников, которым требуется доступ к шлагбауму.

Для этого:

1. Откройте раздел «Мои родственники».
2. Нажмите кнопку добавления.
3. Заполните необходимые данные родственника.
4. Сохраните запись.

После добавления родственник сможет использовать собственные данные (свой номер телефона и пароль участка) для входа после выполнения необходимых условий активации доступа.

Собственник может просматривать, редактировать и удалять записи своих родственников.

## 7. Возможности администратора

Администратор имеет дополнительные возможности:

- Просмотр и редактирование списка собственников.
- Добавление новых собственников.

Администратор видит только родственников, привязанных к его собственной учётной записи. Родственники других собственников ему не отображаются.

## 8. Выход из приложения

Чтобы завершить работу:

1. Откройте главное меню приложения.
2. Нажмите кнопку выхода из аккаунта.

После выхода для повторного использования приложения потребуется авторизация.

## 9. Если шлагбаум не открывается

Если команда не выполняется:

1. Проверьте подключение телефона к интернету.
2. Убедитесь, что вы вошли в приложение под правильной учётной записью.
3. Проверьте, не заблокирован ли ваш аккаунт.
4. Попробуйте повторить запрос через некоторое время.
5. Если проблема сохраняется, обратитесь к администратору.

Возможные причины:

- Нет подключения к интернету.
- Учётная запись не активирована.
- Учётная запись заблокирована.
- Сервер временно недоступен.
- Контроллер шлагбаума не отвечает.
- Возникла техническая неисправность оборудования.

## 10. Рекомендации по безопасности

- Не передавайте свой пароль другим людям.
- Не устанавливайте APK из неизвестных источников.
- Не используйте чужую учётную запись.
- Сообщайте администратору об утере телефона или подозрении на несанкционированный доступ.
- Не пытайтесь открывать шлагбаум повторными нажатиями, пока предыдущий запрос ещё выполняется.
